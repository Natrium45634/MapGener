3.13.18, NumPy 2.5.4, SciPy 1.18.1, Linux-6.18.44-fc-v726-x86_64-with-glibc2.39.
World: seed `Terra7`, window 160×110 hexes × 60 km, default config; world raster
[488, 512] cells of 82.5 km. Ocean run directly (`run_ocean`, 4 years) with
the coupler's season winds, so every ablation uses the same domain and forcing.
Script: `docs/v5_4_1/sst_diag.py` (copy of the run script). SST hash A0:
`8cd9eedd36263717`.

no recorded seed: the original case is therefore not identified; this world is a
diagnostic world, and the "reference" columns are **approximate** literature zonal means
of the observed climatology (nearest ~1 K), not an extraction of OISST
(`observational_validation = NOT_RUN`).
