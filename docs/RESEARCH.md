## Выбор модели плит

| Подход | Плюсы | Минусы |
|---|---|---|
| Симуляция на растре (platec) | причинная история столкновений | результат привязан к разрешению растра; края мира; LGPL |
| Рост областей по сетке | причудливые формы | геология зависит от сетки; связность и обломки приходится чинить |
| Обычный Вороной | просто | регулярная мозаика, равные площади |
| **Взвешенный Вороной + domain warp** (выбран) | функция мировых координат; разные площади; связность по построению; нет краёв | границы плавнее настоящих |

Требования ТЗ, которые решили выбор: геология первична и не зависит от разрешения (принцип 1),
нет искусственных краёв (принцип 5), связность без разрушения форм (п. 4.1).

Геологическая история в духе platec намечена на v1.1 и будет работать поверх этой основы.

### Выбор модели материков

| Подход | Плюсы | Минусы |
|---|---|---|
| Порог шума | просто | положение суши ничем не объяснено; запрещено ТЗ как единственная причина |
| Материк = плита или ячейка Вороного | просто | запрещено ТЗ; материки повторяют мозаику плит |
| Симуляция дрейфа во времени | причинная история | вне объёма v2.0; привязка к растру |
| **Структурное поле в мировых координатах** (выбран) | крупные массивы → структура → тектоника → детали; не зависит от окна; доля коры сохраняется | тектоника — снимок, не история; зоны спайки прямые |

### Выбор модели высот

Высота задана как гипсометрический профиль от знакового расстояния до края коры плюс
тектонические члены от расстояния до границ плит. Так шельф, склон и абиссаль получаются из
одной величины, а береговая линия не совпадает с краем коры: её положение определяет уровень
моря.

### Выбранные алгоритмы v3

| Задача | Выбор | Почему | Что отброшено |
|---|---|---|---|
| Движение плит | точное жёсткое преобразование исходных контуров | нет численного размывания, столкновение нельзя «перепрыгнуть» | полулагранжев перенос по шагам: при шаге меньше ячейки контуры не двигаются |
| Взаимодействия | перекрытие контуров → сближение, разрыв → новая кора | геометрия сама задаёт тип и ширину зоны | классификация по скорости на границе (так было в v1): не даёт ни ширины, ни истории |
| Память породы | поля на исходном растре в материальной системе плиты | пояса едут вместе с плитой | накопление в системе мантии: пояс размазывается на сотни км |
| Возраст новой коры | доля расстояния между осью спрединга и старой окраиной | верно при любой скорости плит относительно мантии | «время первого открытия ячейки»: верно только для симметричного случая |
| Горы | структурный план + аналитический семплер | нет швов между окнами, перевалы и вершины — объекты | шум по маске: запрещён ТЗ |
| Главный хребет | путь наименьшей стоимости между дальними концами системы | следует за гребнем пояса и изгибается с ним | ось по главной компоненте: ломается на дугах |
| Эрозия | склоновая диффузия + сток с площадью водосбора через треугольную систему | один проход на C-скорости вместо цикла по ячейкам | цикл Python по 260 тыс. ячеек на шаг |
