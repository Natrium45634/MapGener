## 2. Что изменилось по ходу работы (решения по реализму)

1. **Параллельные «гребёнки» рек.** На гладких плоскостях макрорельефа D6 давал прямые
   параллельные реки через гекс. Проверены три пути:
   - микрошероховатость рельефа не помогла, код убран;
   - повышенный порог водосбора помогает, но убирает и притоки;
   - выбран Rho8 — стохастический выбор нижнего соседа, зафиксированный сидом.
   Сеть стала древовидной, показатель Хака вырос с 0,51 до 0,54 (Земля 0,5–0,6). Режим
   `steepest` оставлен.
2. **Генерализация.** Целые системы с водосбором в устье меньше 8 гексов не показываются
   (коротких параллельных прибрежных ручьёв на Земле много, но они ниже масштаба карты).
3. **Сухие котловины.** Бессточная впадина, где приток испаряется раньше, чем
   образуется озеро, — больше не «озеро из 0 клеток», а отдельная сухая котловина.
4. **Глубина пересчёта.** Смена уровня моря, снимка, добавление v2/v3 сохраняют глубину
   проекта (раньше проект v2 молча получал геоисторию).
5. **Воспроизводимость после загрузки.** Свежий результат эрозии округляется до
   float32, как в файле: проект, загруженный с диска, и только что сгенерированный дают
   одинаковые реки при пересчёте только сети.

Все четыре случая прошли проверку v4 (`validation.ok`).

- **Климат** считается на мировом растре (~60 км) и почти не зависит от размера окна.
- **Связка эрозии** растёт с числом гексов: priority-flood и неявная схема — циклы Python
  по всем гексам на каждом шаге.
- **Смена порога реки** пересчитывает только сеть рек.
- **Смена уровня моря** пересчитывает v4 целиком: береговая линия меняет сток.

GUI под Xvfb, Terra7 360×240:
- генерация в фоновом потоке — 40 с;
- переключение любой из десяти вкладок с перерисовкой — 0,17–0,33 с;
- «Пересчитать только v4» после смены порога реки — 1,1 с (климат и эрозия взяты из кэша).

## 5. Сравнение с Землёй

Полные таблицы трёх миров — `docs/realism_v4.md`, изображения —
`docs/diagnostics/v4/` (`python tools/climate_gallery.py`). В правдоподобном диапазоне:
**Terra7 — 19 из 21, Mundo42 — 18 из 21, Kq3Lm — 17 из 21** показателей.

Совпадает во всех трёх мирах:
- средняя высота суши, доля суши выше 2000 м, средняя глубина океана;
- зональные температуры до 60°;
- средние осадки на суше;
- доля бессточных областей;
- показатель Хака 0,51–0,60 (Земля 0,5–0,6);
- размыв 36–48 м/млн лет (Земля 20–60).

Расходится повторяемо:
1. **Коэффициент стока 0,50–0,65 против 0,36–0,40.** Избыток даёт суша выше 55°: PET от
   одной температуры там почти нулевой. Осреднение PET по годовому циклу проверено и
   отвергнуто: оно почти не помогло и ухудшило долю аридных земель. Решение — радиационный
   PET (Приестли — Тейлор), см. `docs/REALISM_ANALYSIS.md`.
2. **Высокие широты на 6–8 °C холоднее земных:** нет тёплых океанских течений.
3. **Отношение ветвления Хортона 5,6–6 против 3–5:** грубая сетка.
4. **Озёр мало (0–1 % суши против 1,8 %):** нет ледниковых озёр и озёр мельче гекса.
5. **Доля аридных земель зависит от мира:** у Mundo42 0,36 при земных 0,20, потому что
   много суши в субтропическом поясе. Это свойство конкретного мира, а не ошибка модели.

## 6. Ограничения и что не сделано

1. **Windows: NOT VERIFIED.** Windows-окружения не было.
2. **GUI real display: NOT VERIFIED.** Окно запускалось на настоящем X-сервере (Xvfb, Qt
   `xcb`) — это ближе к реальному запуску, чем offscreen, но физического монитора,
   масштабирования HiDPI и ввода мышью человеком не было.
3. Климат — параметризация: нет сезонного хода, муссонов, океанских течений, облачности
   и радиационного баланса.
4. Одно русло на гекс; меандры, рукава, дельты, эстуарии — следующая часть.
5. Ледниковая эрозия, U-долины, фьорды не реализованы; есть климатический потенциал льда.
6. На карте 1000×800 связка эрозии занимает основную часть времени v4 (циклы Python).
   Если понадобится ускорение — переносить priority-flood и неявную схему в
   скомпилированный код (Numba или C++ рядом с PMGE).
7. Пороги рек в гексах: при другом разрешении меняется густота показанной сети.
8. Исследование аналогов — по README, страницам и статьям; хэши коммитов не
   зафиксированы (API GitHub недоступен из среды).
