# Недра и месторождения (ТЗ 5.5.1) — как пользоваться

Включение: «Новый мир → Ресурсы → Недра и месторождения (5.5.1)» (по умолчанию включено для
новых миров; старые сохранения не пересчитываются и открываются как были). Там же «Частота
месторождений» — множитель всех интенсивностей; геология от него не меняется.

## Что генерируется

* **Провинции и месторождения.** Для каждого из 92 генетических типов проверяются
  обязательные условия (порода, бассейн, магматизм, климат, вода); если для условия нет данных,
  гекс считается «нерешённым», а не пустым. Число месторождений — по физической площади
  провинции, не по числу гексов.
* **Рудные тела с настоящей геометрией:** жилы и сети жил, пласты, линзы, штокверки,
  трубки, россыпи, коры выветривания, карьерные толщи, коллекторы. У тела есть простирание,
  падение, **истинная мощность** (поперёк жилы), длина и протяжённость по падению,
  глубина кровли ниже поверхности. Масса и размер согласованы.
* **Содержания в своих единицах:** %, г/т, ppm, карат/т, г/м³. Попутные элементы (Ga в
  бокситах, Re в молибдените, Cd/In/Ge в сфалерите) — только при минерале-хозяине.
* **Самоцветы:** минерал-носитель, доля ювелирного сырья, размерные классы, разновидность
  (рубин — только с хромом рядом, изумруд — бериллий и хром/ванадий); пустые кимберлиты
  бывают, алмазов «просто так» нет.
* **Россыпи** образуются только из размытых коренных тел и идут вниз по рекам; без источника
  россыпи нет. Масса учитывается до грамма: что не осело — рассеяно, ушло в море или за край.
* **Нефть и газ:** нефтематеринская толща, зрелость по глубине и времени, ловушка только с
  покрышкой и сформированная до прихода нефти, объём пор, стандартные объёмы. **Уголь** —
  ранг по температуре погружения. **Воды:** запас, отдаваемая вода и питание раздельно.
  **Геотермия:** тепло в недрах (Дж) и тепловой поток (Вт) раздельно.

Все численные параметры **предварительные (provisional)**: калибровочных данных в ТЗ нет.

## Вкладки

* **«Недра и месторождения (5.5.1)»** — группа сырья в «Режиме»; галочки «кровля ≤ 25 / 100 /
  500 / 1000 / 3000 м» прячут глубокие тела (не удаляют); «Только с выходом на поверхность».
  Подкрашен гекс, который пересекает тело; линии — проекция жил и пластов в истинную длину.
* **«Геология недр (5.5.1)»** — выведенные породы, мощность осадков, возраст коры, гексы без
  данных для условий.
* **«Гидрогеология и топливо (5.5.1)»** — нефтегазовые ловушки, уголь и торф, водоносные
  горизонты, рассолы, геотермия, гидраты.
* **«Ресурсы по видам»** берёт данные 5.5.1, если они есть.

## Гекс и разрез

* Щелчок по гексу → раздел «Недра и месторождения (5.5.1)»: все тела, которые пересекают гекс
  (а не только его центр): форма, кровля, истинная мощность, простирание/падение, масса,
  содержания, происхождение.
* Правая кнопка мыши — линия разреза: тела рисуются своими реальными интервалами по
  глубине; внизу подписано вертикальное преувеличение. Маленькое тело между точками
  профиля показывается в ближайшей точке.

## Экспорт

«Мир → ⛏ Экспорт недр 5.5.1»: `minerals_footprints.geojson` (проекции тел; координаты —
плоские км мира, **не** широта/долгота), `minerals_lots.csv` (уникальный ключ лота, сырьё,
количество, единица, группа неаддитивности), `minerals_plan.json` (план и журнал масс),
`minerals_manifest.json`.
