## Отклонено

- **k-medoids для TU** — недетерминирован по порядку и медленный на 800 000 гексов;
  стратификация даёт те же совместные классы с точным весом площади.
- **Полный расчёт горизонта по подгексовой ЦМР** — ЦМР нет; ближнее поле по выборкам гекса
  + лучи по 95-му перцентилю гексов до 100 км (`approx_multires_horizon`).
- **Smith–Barstad** (P2) — нужен непрерывный рельеф на сетке; отложено до версии без гексов.
- **Mass-elevation effect** — выключен (амплитуда 0) до калибровки, как требует ТЗ 3.4.
