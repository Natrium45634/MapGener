# Снег, фирн, лёд: баланс массы

Три резервуара на сухом участке, мм водного эквивалента на плановую площадь:
`snow` (снег года), `firn` (пережил сезон таяния; средний возраст и плотность),
`ice` (ледниковый лёд, толщина `H = ice/1000 · 1000/917` м).

Каждый месяц (год начинается после самого тёплого месяца участка): снегопад по гладкой
фазе (−1..+2 °C), сублимация (12 % PET в морозные месяцы), таяние градусо-днями: сначала
снег (3,5 мм/°C·сут), затем фирн, затем лёд (7 мм/°C·сут). В конце года выживший снег
переходит в фирн, а часть фирна старше возраста закрытия пор (плотность 830 кг/м³) — в
лёд. Каждый перенос перемещает массу и не создаёт её.

Течение льда: упрощённое уравнение мелкого льда по графу гексов,
`dH/dt = b/ρ_i − div q`, `q = −D ∇s`, `D = Γ H⁵ |∇s|²` (Глен, n = 3,
A = 10⁻¹⁶ Па⁻³ год⁻¹). Шаг явный, `D` ограничен для устойчивости. Каждое ребро считается
один раз, поэтому объём сохраняется; лёд, ушедший в море, считается откалыванием.

Засев древнего льда (`paleo_ice_initialization`): лёд до 1800 м засевается только там, где
средняя годовая температура ниже −9 °C **и** выпадает снег (> 50 мм/год). Такие гексы
помечены `ice_initial_condition`. Дальше лёд следует современному балансу (тест T16: при
отрицательном балансе масса убывает постепенно).

Бюджет на участке: `M_end = M_start + снегопад − таяние − сублимация + приток − отток`;
невязка в тестах ≤ 1e-6 мм, на картах ~1e-8 мм.
