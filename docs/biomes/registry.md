# Реестр классов (biome_registry_v1)

`src/hexworld/biomes/registry.py`, список `BIOMES` (113 классов). Числовой код — позиция в
списке; список **только дополняется** (тест `test_v1_registry_codes_are_append_only`).

Группы: пустыни и безрастительные земли, тропические / субтропические / умеренные / бореальные
леса, редколесья, саванны, степи и луга, кустарники, высокогорья, тундры, полярные пустоши,
снег / фирн / лёд, болота, пресные воды, море. Полный список с русскими и английскими
названиями и цветами сохраняется в `biomes.json -> biome_registry`.

Отдельно хранятся:
- `COVER_CLASSES` — непересекающийся физический покров (сумма 1): растительность, голый грунт,
  скалы, песок, соль, многолетний снег, фирн, ледниковый лёд, открытая вода;
- `LIMITING_FACTORS` — биты причин ограничения (холод, засуха, соль, лёд, ...);
- `MODIFIERS` — биты местообитаний (оазис у реки, облачный пояс, холодный карман, ...);
- `REALMS` — суша / внутренние воды / море / переходная зона.
