# Биомы v5.0: архитектура

```text
v4.6 рельеф и связность воды, v4 климат/реки/озёра, v4.5 почвы и вода,
v4.7 участки рельефа (TU) с месячным климатом
  -> адаптер входов (_units_from_project): TU или один грубый участок на гекс
  -> криосфера: снег / фирн / лёд (biomes/cryosphere.py), разгон 100 лет,
     засев «древнего» льда (документированный сценарий), течение льда по графу гексов
  -> признаки (pft.Features): холодный/тёплый месяц, GDD, AET/PET, сухие месяцы, PAR,
     почва, переувлажнение, соль, снег, термический балл 4.7, облачность
  -> PFT: пригодность, индекс продуктивности, доля растительности V (голое остаётся голым)
  -> классификатор (biomes/classify.py): причинный порядок правил
  -> агрегация: CSR-доли по гексам, покров, доминирующий класс, зона Кёппена
  -> BiomeData (project.biomes), сохранение biomes_*.npz + biomes.json
```

- Новый производный слой: климат, вода, почвы и рельеф только читаются.
- Обратной связи растительность → климат нет (выключена по ТЗ 2.1).
- Режим `equilibrium`: потенциальная естественная растительность, `potential_only`.
- Код без Qt: `biomes/*` и `pipeline_v50.py` не импортируют PySide6.
- Детерминизм: случайности нет (всё из полей), порядок блоков не влияет на результат.
