# Пресеты v5.0 [П]

Фрагменты конфигурации: объединяются с полной конфигурацией (`Config.to_dict()`) и
загружаются через `Config.from_dict`. Это стартовая калибровка для проверки сценариев ТЗ 16.1,
а не природные константы.

| Файл | Что меняет |
|---|---|
| `earthlike.json` | профиль по умолчанию |
| `hot_hyperarid.json` | осадки ×0,25, +4 °C: гипераридные пустыни, эрги, регы, солончаки |
| `polar_ice_sheet.json` | −14 °C, разгон 300 лет, засев древнего льда: щиты, фирн, нунатаки |
| `alpine.json` | точная выборка 4.7: горные пояса, ледники, осыпи |
| `tropical_monsoon.json` | широта 12°, сильная сезонность: муссонные леса и саванны |
| `continental_cold_desert.json` | осадки ×0,35, −6 °C, без древнего льда: холодные пустыни |
| `coastal_wetland_quality_limited.json` | по умолчанию; мангры и приливные марши остаются нерешёнными (нет модели прилива) |
