# Приёмка v4.7 — высотная поясность, топоклимат, субгексные условия

Версия 4.7.0, 22.11.2026. ТЗ — `HEXWORLD_TZ_4.7_ALTIMONTANE_TOPOCLIMATE.md`.
Аудит входов — `docs/v4_7_baseline_audit.md`; источники — `docs/research/v4_7_sources.md`.

## Что сделано

Конвейер (`src/hexworld/pipeline_v47.py`, модули `src/hexworld/topoclimate/`):

```text
v4.6 поверхность + вода v4.6/v4 + план гор v3 + месяцы, почвы, вода v4.5 (одна ревизия)
 -> выборка поверхности гекса (12 / 48 точек), вода внутри гекса (суша / озеро / море)
 -> участки рельефа (TU): форма × высотная полоса × экспозиция, веса по площади
 -> уклон, экспозиция, ранг высоты, горизонт (ближний + лучи 100 км), SVF, Sx против ветра
 -> по TU и месяцам: T от опорной высоты, радиация на склоне с тенью, холодные карманы,
    прогрев склонов, RH (синтетика), облака/туманы, осадки (сумма гекса сохранена), снег
 -> ядро воды v4.5 на каждом сухом участке
 -> суточная кривая -> GSL/GST, запас тепла, пояса, граница деревьев, снеговая линия
 -> доли площади по гексу, гипсометрия, сводки по массивам, валидация, сохранение
```

Участки рельефа задаются точками в мировых координатах; гекс только группирует их.
Версия без гексов сможет подать на тот же конвейер свои точки выборки.

## Реализм

- Региональная термическая граница деревьев по массивам: 0,4–0,5 км в высоких широтах,
  1,2–2,1 км в умеренных, 2,9–3,2 км в тёплом поясе (Aurelia4 1000×800, Terra7, 500×300).
  На Земле — у полярной границы леса ~0 м, в Альпах 1,8–2,2 км, в тропиках 3,5–4 км.
  Тропическая граница HexWorld ниже: нет mass-elevation effect (выключен до калибровки)
  и задан постоянный Γ = 6,5 K/км (в тропиках влажноадиабатический ближе к 5–5,5).
- Пояса — доли площади участков: в одном гексе массива 2–5 поясов; средняя высота гекса
  не определяет пояс.
- Поправка рельефа к температуре гекса в среднем 0,03–0,14 °C. Это малая величина:
  высоты участков симметричны относительно средней по гексу, остаются только холодные
  карманы и солнце. В отдельных долинах и на склонах — до ±2–3 °C.

## Ограничения (честно)

- Подгексовой ЦМР нет: вне массивов поверхность гекса гладкая (барицентрическая).
- RH, облачность и месячный ветер — proxy (флаги в `topoclimate.json → provenance`).
- Smith–Barstad и итерации T/RH (P2) не реализованы.
- GUI проверен в Xvfb (рендер всех вкладок и режимов); **на физическом экране Windows —
  NOT VERIFIED**.
- Граница деревьев — термический потенциал, а не лес; пояса — не биомы.
