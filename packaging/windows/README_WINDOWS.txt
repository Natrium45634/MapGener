HexWorld 1.0 — генератор карт миров
====================================

Установка
  Запустите HexWorld-1.0.0-Setup.exe и нажимайте «Далее». Права администратора не нужны
  (программа ставится для вашего пользователя; можно выбрать «для всех пользователей»).
  Ничего дополнительно устанавливать не нужно: Python и библиотеки уже внутри.

Первый запуск
  Откройте HexWorld из меню «Пуск» или значком на рабочем столе. Сразу откроется окно
  «Новый мир»:
  - сверху — сид мира (любые буквы и цифры) и кнопка «🎲 Случайный сид»;
  - во вкладках — все настройки: число плит, доля суши, количество островов, горность,
    температура, влажность и т. д. У каждой — ползунок и замок 🔒 (замок не даёт менять
    значение при случайном выборе);
  - справа — эскиз будущего мира, он обновляется сам через секунду после изменений;
  - внизу справа — «Случайные настройки», «Случайно и старт», «Старт».

Карта
  Колесо мыши — приблизить/отдалить, перетаскивание — сдвиг карты.
  Щелчок по гексу — справа откроется «Информация о гексе»: высота, климат по месяцам,
  реки, почвы, биомы, геология. Двойной щелчок — приблизить. Home — вся карта.
  Правая кнопка мыши — провести линию разреза (профиль рельефа и климата).
  Вкладки над картой — разные слои: плиты, высоты, климат, реки, биомы, ледники…

Меню «Мир»
  Новый мир (Ctrl+N), Пакет миров (Ctrl+B — много эскизов сразу, выберите лучший),
  Мои миры (Ctrl+L — история и избранное, сравнение двух миров), открыть/сохранить,
  экспорт для игровых движков (карта высот 16 бит, биомы, реки, таблица гексов,
  инструкция для Unity / Unreal / Godot), PNG-картинки.

Меню «Вид»
  Глобус (Ctrl+G), названия на карте, панель информации о гексе.

Код мира
  Кнопка «📋 Код мира» в окне «Новый мир» копирует короткую строку «HW1-…». По ней
  этот же мир можно получить снова на любом компьютере («📥 Вставить код…»).

Сколько ждать
  Маленький мир — около минуты, большой (1000×800) — несколько минут. Окно прогресса
  показывает этап, проценты, сколько прошло и сколько осталось; «пульс» в нём движется,
  даже когда этап долгий, — программа не зависла.

Удаление
  «Параметры Windows → Приложения → HexWorld → Удалить» или ярлык «Удалить HexWorld»
  в меню «Пуск». Ваши миры («Мои миры») хранятся в %APPDATA%\HexWorld.
