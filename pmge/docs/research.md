## Выбранные алгоритмы

| Задача | Выбор | Почему | Отклонено |
|---|---|---|---|
| Структура | граф хребтов из полилиний, вершины и перевалы как объекты | п. 1 и 10 ТЗ: структура первична; перевал по построению — седловина между двумя вершинами | ridged multifractal / fBm как основа (запрещено ТЗ) |
| Поверхность | аналитическая `H(x, y)` с индексом по ячейкам | точечные запросы без карты, нет швов между чанками и LOD | материализация heightmap и пересэмплирование |
| Тело гор | купол вокруг осей + долины между отрогами | без него хребты выглядели «червями» (проверено на изображениях) | только сумма профилей хребтов |
| Деталь | 3 октавы ridged-шума от хэша координат, только внутри гор | без таблиц и глобального состояния, детерминизм | Perlin с таблицей перестановок |
| Эрозия | термическая (talus) и stream power по убыванию высоты | две простые модели с проверяемыми свойствами: сохранение массы, только понижение | капельная гидравлическая — зависит от порядка капель, сложнее для детерминизма |
| Случайность | splitmix64 от `hash(seed, сущность)` | одна и та же вершина получает тот же ID при любом порядке | `std::mt19937` + глобальный порядок вызовов |
