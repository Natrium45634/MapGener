# Интеграция PMGE с HexWorld

1. HexWorld прогоняет геологическую историю и строит свой структурный план гор
   (`hexworld.mountains.plan`): системы, главный хребет по гребню пояса, ветви, отроги,
   вершины, перевалы, долины — в мировых км.
2. Адаптер `hexworld.mountains.backend.PmgeBackend` переводит км в метры и вызывает
   `pmge_plan_create_external`: оси, высоты гребней, полуширины, остроту по возрасту системы,
   долины, а также растр орогенного рельефа (амплитуду) и растр доли рельефа, отдаваемой
   структуре (gain), — оба на мировой сетке истории.
3. Для гексов HexWorld вызывает `pmge_sample_batch` и применяет дельту только внутри горных
   систем, защищая берег и морское дно; затем ставит общий потолок высот.

Выбор модуля: `mountains.backend = "auto"` (по умолчанию) берёт PMGE, если библиотека найдена
(`HEXWORLD_PMGE_LIBRARY`, затем `pmge/build/`), иначе встроенный модуль с предупреждением;
`"pmge"` требует библиотеку; `"reference"` — всегда встроенный модуль. Фактически
использованный модуль входит в ключ стадии гор, поэтому проект, посчитанный с PMGE, не
загрузится молча с горами другого модуля.

Проверено тестом `test_pmge_backend_through_the_c_abi`: тот же мир с обоими модулями;
вне гор совпадение до 1 м, в горах медиана расхождения меньше 50 м (разная мелкая деталь),
план гор одинаковый.
