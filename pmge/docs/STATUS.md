# PMGE 0.1 — статус по ТЗ

Статусы: **сделано и проверено тестом** / **сделано без теста** / **частично** / **не сделано**.

## Критерии готовности (п. 19)

| Критерий | Статус |
|---|---|
| собирается, тесты проходят | сделано и проверено (Linux, GCC 13); MSVC и macOS не проверялись |
| `sampleHeight` и `sampleHexes` работают без полной карты | сделано и проверено |
| local patch не меняет посторонние области | сделано и проверено (вне области дельта ровно 0) |
| граф хребтов и перевалов согласован | сделано и проверено (перевал — седловина между двумя соседними вершинами одного хребта) |
| несколько типов вершин | сделано и проверено: 8 типов, попарно различимые профили |
| хотя бы две модели эрозии | сделано и проверено: термическая, по стоку |
| чанки сшиваются | сделано и проверено: побитовое совпадение на общей границе и между разными LOD |
| C API документирован | сделано: `include/pmge/pmge.h`, `docs/architecture.md` |
| демо реально генерирует рельеф | **частично**: есть CLI, пишущий heightmap и план; графического демо-редактора нет |
| исследование с проверенными проектами и лицензиями | **частично**: обязательный перечень на уровне README; исходники и литература не изучены; 10 доп. проектов нет |

## Прочее из ТЗ

| Пункт | Статус |
|---|---|
| C ABI: opaque handles, ownership, коды ошибок, версия ABI | сделано и проверено |
| C++ RAII-обёртка | **не сделано** (есть внутренние C++-типы, публичной обёртки нет) |
| Python bindings | частично: ctypes-обёртка в HexWorld, отдельного пакета нет |
| JSON-конфигурация запроса с версией | **не сделано**: есть JSON плана на выход, входной JSON не читается |
| асинхронные вызовы, отмена, приоритеты, хуки | **не сделано** |
| `continueRange` по ID горной системы | **не сделано**; продолжение через чанки работает, т. к. план общий |
| ConstraintSolver: якоря, защищённые области, граничные высоты и уклоны | **не сделано** (только абсолютные пределы и constrained_fit) |
| типы вершин: иглы и зубцы есть; «составные» | составных нет |
| долины V/U, запрет пересечения вершин | сделано: профиль от зрелости; долина не режет гребень |
| гидрологически согласованные долины, реки, бассейны | **не сделано** |
| ледниковая эрозия | **не сделано** |
| гекс-адаптер: flat/pointy, центр/вершины/равномерно, классификация | сделано и проверено |
| проходимость и стоимость движения | не сделано (по ТЗ — опциональный адаптер игры) |
| экспорт RAW / PNG16 / GeoTIFF | частично: PGM 16 бит в CLI; RAW, PNG16, GeoTIFF нет |
| демо-редактор (2D/3D, рисование хребтов, Undo/Redo) | **не сделано** |
| GPU-бэкенд | не сделано (по ТЗ опционально) |
| профили качества Fast / Balanced / HighQuality / Geological | **не сделано** |
| геоморфологические метрики, сравнение с DEM | **не сделано** |
| 8192², потоковые чанки, бенчмарки памяти | не замерялись |
